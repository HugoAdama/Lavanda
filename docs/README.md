# Documentacion Tecnica y de Negocio - LAVANDA

Este directorio contiene la documentacion formal de la plataforma web de LAVANDA desarrollada con Astro 7.

## Despliegue en Vivo

* **URL de Produccion (GitHub Pages):** [https://hugoadama.github.io/Lavanda/](https://hugoadama.github.io/Lavanda/)
* **Repositorio de Codigo:** [https://github.com/HugoAdama/Lavanda](https://github.com/HugoAdama/Lavanda)
* **Canal de Despliegue:** GitHub Actions (CI/CD automatico en rama `main`)

## Indice de Documentos

1. [01. Arquitectura y Tecnologias Usadas](docs/01-arquitectura-y-tecnologias.md)
   Detalle de la pila tecnologica, arquitectura por capas de responsabilidad, renderizado estatico, configuracion de base path y flujo CI/CD con GitHub Actions.

2. [02. Identidad del Negocio Trasladada a la Web](docs/02-identidad-de-marca-y-diseno.md)
   Traduccion de la propuesta de valor de lavanderia boutique eco-friendly a tokens de diseno, paleta cromatica, tipografia y direccion de arte.

3. [03. Guia de Mantenimiento del Codigo](docs/03-guia-de-mantenimiento.md)
   Manual operativo para modificar contenidos, agregar servicios, actualizar planes de precios, extender componentes y gestionar el despliegue continuo.

4. [04. Aprendizajes y Buenas Practicas](docs/04-aprendizajes-y-buenas-practicas.md)
   Analisis de lecciones tecnicas, conversion de interfaz, eliminacion de emojis del sistema por iconografia vectorial y diseno de microinteracciones.
